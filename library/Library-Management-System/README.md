# 📚 Library Management System


A modern frontend based Library Management System built with HTML, CSS and JavaScript.



## 🚀 Features


- User Login & Signup
- Dashboard
- Book Management
- Add Book
- Edit Book
- Delete Book
- Search Book
- Category Filter
- Book Quantity System
- Pagination
- Borrow Page
- Member Page
- Dark Mode
- Responsive Design
- Local Storage Data Saving



## 🛠 Technologies


- HTML5
- CSS3
- JavaScript
- Local Storage
